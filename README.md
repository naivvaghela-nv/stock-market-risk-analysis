# Stock Market Risk & Covariance Analysis

A Python-based financial data analysis project exploring historical stock returns, volatility, covariance, correlation, and linear relationships between selected stocks.

## Overview

This project uses historical market data to analyze the behavior and relationships between major technology stocks. It calculates daily returns and statistical measures and visualizes the results to understand how different assets move relative to one another.

## Stocks Analyzed

* Apple (AAPL)
* Microsoft (MSFT)
* Amazon (AMZN)
* Tesla (TSLA)
* Alphabet (GOOG)
* NVIDIA (NVDA)

## Analysis

The project includes:

* Historical stock price retrieval
* Daily percentage return calculation
* Return distribution analysis
* Volatility analysis
* Pairwise covariance analysis
* Correlation analysis
* Linear regression between stock returns
* Data visualization using Matplotlib

## Technologies Used

* Python
* NumPy
* Pandas
* SciPy
* Matplotlib
* yFinance

## How to Run

Install the required dependencies:

```bash
pip install numpy pandas scipy matplotlib yfinance
```

Then run the analysis:

```bash
python finance_bro.py
```

## Purpose

The project was developed as an exploration of quantitative finance and statistical methods applied to real-world financial data.
